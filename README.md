# My Gallery

A responsive image gallery website showcasing a collection of 15 images with beautiful hover effects and modern design.

## 🔗 Live Demo

Check out the live demo: [My Gallery](https://ykbeladiya.github.io/My-Gallery/)

## ✨ Features

- Responsive grid layout
- Beautiful hover effects
- Grayscale to color transition on hover
- Image caption reveal on hover
- Smooth scaling animation
- Shadow effects
- Clean and modern design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid (alternative layout option provided in comments)
- CSS Transitions and Transforms

## 🎨 Design Features

- Grayscale images that transform to color on hover
- Smooth scaling animation on image hover
- Caption reveal with gradient background
- Purple shadow effect on hover
- Responsive layout that adapts to different screen sizes
- Clean and minimalist design

## 📁 Project Structure

```
My-Gallery/
├── images/         # Contains all gallery images (image1.jpg to image15.jpg)
├── index.html      # Main HTML file
├── styles.css      # CSS styling file
└── README.md       # Project documentation
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/My-Gallery.git
   ```
2. Open `index.html` in your web browser to view the gallery.

## 💡 Implementation Details

- Uses CSS Flexbox for the main layout
- Alternative CSS Grid layout implementation provided in comments
- Implements modern CSS features like:
  - `filter` for grayscale effects
  - `transform` for scaling animations
  - `transition` for smooth animations
  - Linear gradients for caption backgrounds
  - Box shadows for depth

## 📱 Responsive Design

The gallery is fully responsive and adjusts to different screen sizes while maintaining its aesthetic appeal and functionality.
